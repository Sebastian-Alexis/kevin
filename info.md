The context for this project is the following: This is a hackathon project aimed at
  reforming how agents leverage computer use. Existing computer use is clunky, hard to
  set up proper permisions, and requires extensive software design that ultimately
  limits the possibilities of what can be accomplished. We're building a way (in this
  repository) for agents to have integrated and fast computer use, from the OS /
  Hardware level. The way this works is that it will be a physical device, hosted on a
  Pi Zero that we plug into any computer via usb-c. By plugging it in usb-c, the
  computer reads it as a virtual keyboard and mouse. That way, the computer reads it 
  as a real user. Then, the goal is to train a local, specialized AI model to 
  specifically make actions using this connection and lower latency between action / 
  task runs. It is ultra portable and privacy-first.
