# Task bench on the MacBook (2026-10-24)

12 OSWorld-style tasks (web lookup/navigation, system settings, Finder, TextEdit, Calculator, Gmail, Calendar, browser chrome, multi-app), run with `python3 -m agent` (native computer tool, Opus 5.5, memory on). All 12 completed on the first pass; the slow ones were native-app tasks and traced to three executor-timing faults, fixed the same day:

- launcher pacing: keys sent before Raycast/Spotlight rendered were lost (`cmd+space` now waits for the launcher; the app name gets 0.6 s to resolve; Return waits for the app)
- text typed right after a key combo that opens UI (`cmd+shift+n`, `cmd+n`, `cmd+t`) lost its first characters (a settle before the first character)
- `cmd+Delete` meant Move to Trash but was sent as forward-delete (Mac Delete = HID backspace)

Correctness was checked against ground truth, not `done: true`: GitHub API (3,234 stars; reported "3.2k"), `sw_vers` (26.4), `AppleInterfaceStyle` (Dark), `hw.model` (MacBook Air), the Wikipedia infobox (2012), the Downloads folder (the Moss PDF). All read-only answers were right. Two passes were not clean: `multi-app` read the model name from Spotlight's About panel instead of System Settings (right answer, wrong route), and `textedit`'s first pass left a stray blank TextEdit window running (quit afterwards by a separate run); both count as partial.
